# Contributing

Suggestions, bug reports and improvements are welcome.

## Bug reports

Include:

- CIGA - Lost Signal version.
- OBS Studio version and Windows architecture.
- Steps to reproduce the problem.
- Relevant OBS log messages, after reviewing them for usernames, private paths or other sensitive information.

Do not attach personal information, tokens, credentials or unrelated private logs.

## Code changes

- Keep changes focused and explain their purpose.
- Do not include local build outputs, installers, private backups or recovery scripts.
- Preserve the project's licence and third-party notices.
- Test changes in OBS before claiming compatibility.
- Document which OBS versions and installation layouts were actually tested.

## Pull requests

Describe what changed, how it was tested, and any known limitations. Do not claim an installation layout is supported unless it has been validated.
