# Security Policy

## Supported release

The current release under preparation is CIGA - Lost Signal 0.1.0 for Windows x64.

## Reporting a vulnerability

Please do not publish exploitable details, private logs or personal information in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use that feature. Otherwise, contact the maintainer privately through an available GitHub contact method before disclosing sensitive technical details.

## What to include

When safe to share, include the affected version, OBS Studio version, Windows version, steps to reproduce and relevant error messages with private information removed.
