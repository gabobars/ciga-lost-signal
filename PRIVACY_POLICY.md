# Privacy Policy — CIGA - Lost Signal

Last updated: 15 October 2026

## Scope

This notice covers the CIGA - Lost Signal OBS Studio plugin, its bundled resources and its Windows installer, version 0.1.0.

## Information collection

This release is designed to operate locally on the user's computer through OBS Studio. The plugin does not require a CIGA account. The project is not designed to collect personal information or send telemetry, analytics or advertising data to CIGA servers.

The installer asks for Windows permission to install the plugin files and register an uninstaller. It does not require the user to enter a name, email address or account details.

## Local processing

The transition effect and bundled media are read from the local installation. OBS Studio and Windows may create their own logs, settings or diagnostic information. Those systems are outside the control of this project.

## Third-party services

Downloading this project from GitHub is subject to GitHub's own privacy practices. Use of OBS Studio, Windows and any other software is governed by the policies of their respective providers.

This notice does not claim to describe the privacy practices of OBS Studio, Microsoft, GitHub or other third parties.

## Changes

This notice must be reviewed if a future version adds network communication, telemetry, analytics, online update checks, accounts or other functionality that changes the processing of data.

## Contact

For general questions, use the project's GitHub Issues page without posting personal or sensitive information. Public issues are visible to other users.

This document describes the intended behaviour of CIGA - Lost Signal 0.1.0; it is not legal advice.
